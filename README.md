# 📊 Business Data Management Capstone Project

## Case Study of Studify Consultants -- Data Analysis & Data Management System Proposal

------------------------------------------------------------------------

## 📌 Overview

This project is a real-world business data analysis case study conducted
for Studify Consultants, an overseas education and visa consulting firm.
The goal of this project was to analyze organizational data to identify
business challenges, extract insights, and propose a centralized data
management solution to improve efficiency, lead generation, and
productivity.

------------------------------------------------------------------------

## 🏢 Organization Background

Studify Consultants provides services such as:

-   Student Visa Consulting
-   Tourist Visa Consulting
-   Overseas Education Guidance
-   Permanent Residency Assistance

The organization handles large volumes of customer data critical to its
operations.

------------------------------------------------------------------------

## 🚨 Problem Statement

The organization faced the following challenges:

### 1. Low Lead Generation

-   Limited access to structured customer data
-   Low conversion rate from social media marketing

### 2. Poor Data Management

-   Customer data stored in physical forms and Excel files
-   No centralized database system
-   Slow data retrieval process

### 3. Productivity and Data Security Issues

-   High manual workload
-   Reduced employee productivity
-   Risk of data leakage

------------------------------------------------------------------------

## 🎯 Objectives

The objectives of this project were:

-   Analyze visa application datasets
-   Identify trends and patterns in customer data
-   Improve business decision-making through analysis
-   Propose a centralized customer data management system
-   Improve operational efficiency

------------------------------------------------------------------------

## 📂 Dataset Description

Two datasets were analyzed:

### Student Visa Dataset

-   Gender
-   Age
-   University / College
-   Province
-   Course
-   Intake
-   Application Status
-   Attempt Number

### Tourist Visa Dataset

-   Gender
-   Age
-   Country
-   Purpose of Visit
-   Application Status
-   Attempt Number

------------------------------------------------------------------------

## 🧹 Data Cleaning and Preparation

Steps performed:

-   Removed irrelevant columns
-   Added missing values
-   Calculated age from passport data
-   Filtered duplicate entries
-   Structured datasets for analysis

------------------------------------------------------------------------

## 📊 Analysis Methodology

Tools used:

-   Microsoft Excel
-   Pivot Tables
-   Pivot Charts
-   Statistical Analysis

Analysis included:

-   Demographic analysis
-   Age distribution analysis
-   Country preference analysis
-   Approval rate analysis

## 💡 Proposed Solution

A centralized customer data management system was proposed to:

-   Store all customer data in one place
-   Improve accessibility

-   Improve productivity
-   Improve data security

Proposed technologies:

-   Python
-   Tkinter (GUI)
